Rohan Poddar Portfolio
======================

Personal portfolio website for Rohan Poddar, Data Scientist II.

Live site:
https://rorat23.github.io/rohan-portfolio/

Repository:
https://github.com/rorat23/rohan-portfolio

Structure
---------

- index.html: Homepage with overview, outcomes, career spine, portfolio highlights, and skills.
- generic.html: Detailed experience and public-facing impact summaries.
- elements.html: Resume/profile page with skills, achievements, education, and contact links.
- assets/css/portfolio.css: Custom CSS for the redesigned site.
- images/: Images used by the portfolio.
- Rohan Poddar - Resume.pdf: Downloadable resume.

Local Preview
-------------

Run from the project root:

python -m http.server 8000

Then open:

http://localhost:8000

Deployment
----------

This is a static site intended for GitHub Pages.

Recommended GitHub Pages settings:

- Source: Deploy from a branch
- Branch: main
- Folder: /root

Notes
-----

The portfolio intentionally summarizes professional work at a high level. It avoids publishing internal data, implementation details, fraud logic, model internals, or confidential product mechanics.
